# Nix Environment for Synapse

This directory contains the Nix configuration for creating a reproducible development environment for the Synapse project.

## Overview

The Nix setup is designed to provide a consistent and isolated environment for all developers, ensuring that everyone is using the same versions of dependencies. This helps to eliminate "works on my machine" issues.

## Files

-   `flake.nix`: The main entry point for the Nix flake. It defines the development shell.
-   `shell.nix`: A traditional Nix shell definition, used as a fallback or for compatibility with older Nix clients.
-   `python-packages.nix`: Defines the Python packages required for the project, using `mach-nix` to convert `requirements.txt` into a Nix expression.
-   `all-requirements.txt`: A concatenation of `requirements.txt` and `requirements-dev.txt`, used by `python-packages.nix`.
-   `pip.lock`: The lock file generated by `mach-nix` to ensure reproducible Python package installations.
-   `NIX_VALIDATION_PLAN.md`: A document outlining the plan for validating the Nix environment.
-   `validation-results.txt`: The results of the Nix environment validation.
-   `modules/`: A directory for Nix modules, which are reusable components of the Nix configuration.
-   `flakes/`: A directory for flake-related files.

## How to Use

1.  **Install Nix:** Follow the instructions on the [NixOS website](https://nixos.org/download.html) to install Nix.
2.  **Enable Flakes:** Enable the experimental flakes feature by editing your Nix configuration file (`~/.config/nix/nix.conf` or `/etc/nix/nix.conf`) and adding:

    ```
    experimental-features = nix-command flakes
    ```

3.  **Enter the Development Shell:** From the root of the project, run:

    ```bash
    nix develop
    ```

    This will download all the specified dependencies and drop you into a shell where you can run the project's commands.
